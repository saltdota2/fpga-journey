# Coding style

## Файлы
- Один модуль = один файл, имя файла = имя модуля
- Пакеты в rtl/pkg/, читаются первыми
- Тестбенчи в tb/, префикс tb_

## Директивы
- `default_nettype none` в начале, `wire` в конце каждого RTL-файла
- `timescale 1ns/1ps` в каждом файле

## Порты
- input  wire  — входы
- output logic — выходы
- Один порт на строку
- Суффиксы: _i вход, _o выход, _n активный ноль

## Именование
- модули, сигналы, функции: snake_case
- параметры и константы: UPPER_CASE
- типы: суффикс _t (struct), _e (enum)
- generate-блоки: префикс g_
- экземпляры модулей: префикс u_
- регистр состояния FSM: state / next_state

## Процессы
- Только always_ff и always_comb, никогда голый always
- always_ff → только <=
- always_comb → только =
- Дефолтное присваивание первой строкой перед case
- default в каждом case, даже при полном перечислении enum

## Reset
- Синхронный, активный низкий (rst_n), первой ветвью if
- Сбрасывать control path, не сбрасывать data path

## Параметры
- parameter для настраиваемого, localparam для производного
- Ширины через $clog2 / $bits, не константами
- Проверка параметров через $fatal в initial

## Качество
- Ноль предупреждений Verilator (-Wall)
- Ноль CRITICAL WARNING в Vivado
- Каждый модуль синтезируется автономно
